# Задание 1. Развертывание инфраструктуры в Yandex Cloud

Инфраструктура описана с помощью Terraform и включает:

Созданные ресурсы:

VPC и подсеть

Security Group с правилами:

- TCP 22 — SSH
- TCP 80 — HTTP
- TCP 443 — HTTPS
- TCP 3306 — доступ к MySQL
- Виртуальная машина (VM) для размещения web-приложения
- Managed MySQL кластер
- Yandex Container Registry
- Terraform state хранится удалённо, используется state locking, хардкод отсутствует.

# Задание 2. Установка Docker и Docker Compose через cloud-init

На виртуальной машине используется cloud-init (user-data) для автоматической настройки окружения.

Через cloud-init:

- устанавливается Docker
- устанавливается Docker Compose
- настраивается автозапуск Docker
- подготавливаются директории для приложения и сертификатов
- загружается CA-сертификат для подключения к Managed MySQL

Это обеспечивает полностью автоматизированный старт VM без ручных действий.

# Задание 3. Dockerfile и сборка образа

Для приложения создан Dockerfile с использованием мультисборки.

Образ:

- собирается локально

- используется при запуске контейнера на VM
- Контейнер содержит Flask-приложение и все необходимые зависимости.

# Задание 4. Интеграция приложения с Managed MySQL

Web-приложение запускается в Docker-контейнере и подключается к Managed MySQL.

Передача параметров подключения осуществляется через переменные окружения:

- DB_HOST
- DB_NAME
- DB_USER
- DB_PASSWORD
- DB_SSL_CA

Подключение к БД выполняется по SSL с использованием официального CA-сертификата Yandex Cloud.
Приложение доступно по публичному IP виртуальной машины на порту 80.

# Задание 5*. Хранение пароля БД в Lockbox

Пароль от базы данных не хранится в коде и Terraform.

Используется:

Yandex Lockbox

пользовательский секрет mysql-password

Реализация:

пароль хранится в Lockbox
